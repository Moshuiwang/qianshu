## 4. 验收标准

- 可观察完成标准逐条见[验收.md](验收.md)（E-1～E-8）。
- 证据等级要求：#95 L4（文档档 CI）+ G1 登记；#96 L4 + 实跑；解析类（#55 #56 #58 #69 #70 #82）L4 + 新量尺三次运行报告；发版部署 L5 并回读版本。未达目标等级时，降级关闭须守望者裁定，缺口登记到 040 对应工作项。
- **预批口径（量尺与协议要点；#95 写成长期文档，不得放宽）**：
  - **配对**：每篇申请内，把草稿与冻结的人工配置按业务键打分（国家 / 公司、优惠类型、节目包、充值与赠送天数或金额、用户标签、起止日期重叠），取全局最优一一配对；分数与阈值在 #96 合并时冻结（看候选结果之前），并由一次独立人工式抽核（Codex 调研者 20 对）确认配对正确率 ≥ 95% 才算可用。配不上的人工配置记「漏条」，多出的草稿记「多条」。证据位置不参与配对。
  - **字段评分**：只评冻结分母内的字段。每项归为：正确确定 / 错判确定（状态为确定但值不同，含错误套用默认）/ 多问（人工值可由原文得出却判不确定）/ 合理不确定 / 缺失（未配上）。
  - **主指标**：卡片零修改可确认率 = 配上且全部可比字段「正确确定」的政策数 / 148。辅指标：安全可确认率（配上且无错判确定）、错判确定率（错判确定项 / 可比字段项）、多问率、漏条与多条数。
  - **旧量尺**（严格位置对齐）照旧输出唯一对齐 / 未对齐 / 歧义，只作诊断，不作门槛。
  - **盲测集**：从 0.2.0 冻结考题未用的候选（829 − 148）中，按同一分层规则冻结约 60 条，审定方式同考题集（Codex 审定 + 另一模型交叉核对，分歧逐条记录）；存私有目录，指纹登记在 #94。实施卡与审核卡写明禁止读取该目录；盲测集只在 G1 基线和发版候选上运行，不用于迭代。**残余风险**：Codex 沙箱不限读取，只能靠卡面禁令与回收时核查日志里的路径，见裁定项 2。
  - **波动计法**：凡改了提示词或模型输出结构的版本，冻结考题跑 3 次、盲测集跑 2 次，报均值与最小–最大；只改程序的版本对已存回复离线重放（无波动）。「提升成立」= 候选三次最小值 > 基线三次最大值；「不劣于」= 候选三次最大值的错判确定率 ≤ 基线三次最大值。单次结果不作结论。
  - **门槛**（DG2 在 G1 基线出数后由守望者确认数值；默认按下式自动生效）：主指标三次均值 ≥ 基线均值 + max(10 个百分点, 2 × 基线波动幅度) 且「提升成立」；错判确定「不劣于」基线；冻结变体族上程序侧不变量 100% 成立；盲测集主指标提升 ≥ 冻结考题提升的一半（否则判过拟合，报守望者）。
  - 判据拿不准时默认：判「不确定」或「待人工复核」，不算正确。
- **审核标准（两类，#93 约束 4）**：
  - **安全边界类，一条就拦**：改动 17 处安全边界；程序把模型的非「确定」状态改成「确定」，或证据核对失败仍确定；冻结变体族上程序侧不变量不成立；同一份已存回复重放时，main 上判不确定的字段在候选上变成错判确定；新增按关键词、标点、换行做的语义判断（属格式或查表的须在 PR 说明里逐处标类别）；真实入口行为偏离 main 的约定（如建单字段集合）；凭据或真实数据进入仓库、日志、Issue、PR。
  - **理解类，按比例评**：模型理解错了（某种说法认错），不作为单条拦截理由。审核者提出的理解类反例由编排者加入「变体族补充集」（合成，私有或仓库测试资料均可），在下一次计划内的回归里计入比例；实施者不得为单条理解类反例在程序里补字面规则，只能改提示词、字段说明或协议。
- 既定条款：正式验收在已升版本号的提交上做，前提由脚本核对。
- 既定条款：用户可见断言（部署回读）双通道观测：进程与版本回读 + 服务启动日志。
- 既定条款：证据只认仓库 / GitHub 留痕——审核结论、回归计数、裁定当天落对应 Issue 或 PR；真实数据与原始回复只留私有目录，公开只写计数与指纹。
- 既定条款：产品负责人真人验证块：本版无。
