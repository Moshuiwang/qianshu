# Execution Trace 索引

多批次工作使用 trace-kit `METHOD.md` v27（v0.10.0；方法所在仓库不公开，只写名称与版本号）。Issue 分类、合同批准与审查规则见[协作约定](../协作约定.md#execution-trace)。

## 目录约定

以 `[tracking]` Issue 跟踪一个 Trace，在 `docs/traces/<Issue号>-<短名>/` 保存以下三件套。

| 文件 | 记录内容 |
| --- | --- |
| `合同.md` | 目标、授权终点、边界、验收标准、成本预算、主线与角色表 |
| `任务表.md` | 批次、工作项、依赖、进度和证据指针 |
| `验收.md` | 各 Epic 的可观察完成标准、目标与实际证据等级、证据指针及未验证项 |

起草 `验收.md` 时，证据等级引用[验证与门禁](../验证与门禁.md#证据等级)。从 Trace 目录使用相对链接 `../../验证与门禁.md#证据等级`。估时与收口回写参照[时间校准](时间校准.md)。
