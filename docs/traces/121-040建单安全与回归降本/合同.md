## 4. 验收标准

- 可观察完成标准逐条见[验收.md](验收.md)（E-1～E-10）。
- 证据等级要求：#63 L4（CI 文档档与完整档各在正式 PR 上实跑一次）；#113 L4 + 真跑（快检即时 1 次、全量批量 1 次）；#114 #118 L4 + 快检真跑；#117 研究结论（L1）+ 每组计数报告；#108 L4 + 含附件篇目真跑；#57 #62 #64 #71 #61 L4（合成服务端 / 合成时序 / 合成崩溃注入）；发版部署 L5 并回读版本。未达目标等级时，降级关闭须守望者裁定，缺口登记到 050 对应工作项。
- **放行四项（沿用 030 v1.7，与 v0.3.0 基线比）**：

  | 放行项 | 判据 |
  | --- | --- |
  | (a) 错判确定 | 每次错判确定项数 ÷ 当次配上的可比字段数 ≤ max(基线同口径最大值, 2%)，且每次 ≤ 15 项；并列报以冻结可比字段为分母的旧口径 |
  | (b) 漏条 | 各次最大值 ≤ 基线最大值 |
  | (c) 多问率 | 各次均值 < 基线均值（分母沿用冻结可比字段） |
  | (d) 最终回复解析失败 | 按篇计，只看每篇最终那次尝试；每次 ≤ 基线最大值。#114 合并后目标为 0，不达 0 不挡放行，如实报 |

  - **基线**：v0.3.0 上的全量 3 份录制（030 终验那 1 份，若其提示词与请求和 v0.3.0 标签一致；加 #113 验收时在 v0.3.0 上跑的 2 次批量）。不一致时从 §5 预留补 1 次。快检档的基线由这 3 份录制按快检篇目取子集离线计分得出，不另跑。留集基线沿用 030 终验的盲测集、节目包补充集各 1 份。基线数值由编排者在 #113 合并时登记到 #121，守望者确认后冻结。
  - 冻结变体族上程序侧不变量须 100% 成立；安全边界类一条就拦。
  - 判据拿不准时默认：判「需人工确认」或「未知」，不算正确。
- **分级与调用方式的选择（#113 卡面，由编排者按原则决定）**：只改程序 → 离线重放已存录制，不调模型；改了提示词或请求、方向试验 → 快检档（默认即时）；关卡判定与发版终验 → 全量 3 次（默认批量）+ 留集（默认批量）。每次在 #121 写一行「档位 + 方式 + 理由 + 费用」。
- **#117 判据（卡面）**：某组在快检档上至少两项明显好于对照、另两项不劣于对照，才扩大到全量档复验；样本量不足以区分的记「未知」，不以单次结果下结论。对照组 = v0.3.0 单次调用 + Sonnet，取快检基线（离线子集，不另跑）。
- **审核标准（两类，沿用 030）**：
  - **P1 只有三类**：程序做了语义判断；动了安全边界，或任何路径能让未经卡片同意的内容写入、让凭据或真实数据外泄；与已定业务口径冲突。另加本版两条：违反「协议要薄」四条；原有安全测试被改动或删除。
  - 「构造一份回复，它能骗过程序」不是 P1，除非直接导致第 2 类后果；理解类问题按比例评，只登记到 #121 诊断清单，不增加审核轮次。
  - 审核者不提「程序再加一层检查」的改法，除非那层检查纯属结构核对。
