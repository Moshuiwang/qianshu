## 批终链（全绿才进下一阶段）

改法说明经审核短审并在卡上留痕 → 本机受影响测试绿 → 冻结候选跑本机全量 → 只改程序时用已存录制离线重放四项，改了提示词或请求时按合同 §5 运行表真跑（先单篇试通）→ Codex 审核者审一次 → 修复 ≤ 2 轮、定向复核 ≤ 2 次 → 需要时 agy 审最终 SHA → 推送开 PR → CI 完整档 → 合 main。发版阶段：冻结候选 → S-3-2 终验 → 必要时修复包并重建候选 → 发版 PR 两层审核与脚本核对 → 守望者合并并推标签 → 部署回读。冻结后回填：候选 SHA `________`；门禁 run `________`。
