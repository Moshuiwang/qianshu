## 批终链（每个代码 PR）

快检绿 → 唯一内审一次 → 修复包 → 同一审核者定向复核（只复核 P0/P1）→ 第二层外审处置 → 冻结候选 → CI 绿 → 合并 → 碰真实外部系统的 Step 在冻结候选上先做一次只读真实冒烟。正式验收（收口块）在 #15 版本号提交上做（任务表 S-5-0 → S-5-2）。冻结后回填：候选 SHA `________`；门禁 run `________`。

## 未验证层级（收口时如实列）

- 机器人专用运行账号下运行：不在本版（合同 §3）。
- 正式单建单、知识库汇总页登记：不在本版。
- 登录状态多久失效（F4.4）：本 Trace 只观察，不作断言。
- 大批量建单的节奏与同国家重算影响：只建 1 条测试单，未验证。
