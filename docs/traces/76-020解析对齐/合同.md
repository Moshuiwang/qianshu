## 4. 验收标准

- 可观察完成标准逐条见[验收.md](验收.md)（E-1～E-8）。
- 证据等级要求：解析类（#55 #56 #58 #69 #70 #37）至少 L4 + 回归报告（L3 级的本地真实数据评测）；#73 至少 L6（X3 真人 @）；#74 L4；文档类 L4（文档档 CI）；部署 L5 并回读版本。未达目标等级时，降级关闭须守望者裁定，缺口登记到 0.3.0 对应工作项。
- **预批口径**：
  - 回归一致率：按裁定项 3（默认：不设绝对门槛；已有字段改动后不得低于改动前基线超过 2 个百分点；新字段只报计数）。
  - 回归比对的「一致」：枚举值、日期、天数逐字相等；名称按完整字符串；节目包按行集合（包名、赠送包）相等，行序不计。
  - 判据拿不准时默认：判「不确定」或「待人工复核」，不算一致。
- 既定条款：正式验收在已升版本号的提交上做，前提由脚本核对。
- 既定条款：用户可见断言（X3）双通道观测：群消息回读（飞书接口）+ 服务日志，两者一致才定论。
- 既定条款：证据只认仓库 / GitHub 留痕——审核结论、回归计数、真实验证结果一律当天落对应 Issue 或 PR 评论；真实数据与模型原始输出只留私有目录，公开评论只写计数。
- 既定条款：产品负责人真人验证块只放一处——X3，排在 #73 合并后、产品负责人在线时段（见裁定项 5），先出示就绪自检，一次只给一条指令。

## 5. 成本预算

- **完整门禁**（本机全量测试 + 该 head 的 CI）：≤ 28 次（13 个 PR × 约 2 次，另余 2 次）/ 守望者可追加 8 次。
- **时间窗**：合同合并起 ≤ 16 小时机器工作时间，不含等产品负责人；可跨夜。硬期限：无。
- **CI 计划**：
  - 本地门禁：实施卡只跑受影响测试；冻结候选跑一次全量。本机全量单次约 5 分钟（开工快照，单点样本）；冻结候选才跑，13 次合计约 65 分钟，与下一张卡的实施并行。
