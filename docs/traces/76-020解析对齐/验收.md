## 批终链（全绿才进下一阶段）

本机受影响测试绿 → 冻结候选跑本机全量 → Codex 审核者审一次 → 一轮修复 → 同一审核者定向复核一次 → 推送开 PR → CI 完整档 → 合 main。整合阶段：发版候选（含版本号）冻结 → S-4-2 回归终验（冻结清单）→ 必要时整合前修复包并重建候选、重跑 → 发版 PR 在最终 SHA 上两层审核，终验 SHA 与最终候选 SHA 一致（或差异不碰解析代码与规则）→ 守望者合并并推标签 → 部署回读。碰 `src/qianshu/mingdao/`、依赖或配置的 PR 在最终 SHA 上两层定向复核。冻结后回填：候选 SHA `________`；门禁 run `________`。
